# Product

## Register

product

## Users

Obsidian users on macOS who maintain a personal knowledge system and want local, inspectable automation for notes, Apple Books annotations, semantic links, and optional grounded research. They work inside Obsidian and need operational state without leaving their writing context.

## Product Purpose

Mindmap turns eligible vault notes and reading annotations into structured, connected knowledge using local models. It makes queues, scheduler health, Reading Mode, and optional Web Research understandable and controllable while preserving source content, privacy, and recoverability.

## Brand Personality

Quiet, native, trustworthy. The plugin should feel like a well-integrated Obsidian capability: concise when healthy, explicit when action is required, and technically transparent without exposing noisy implementation details.

## Anti-references

Avoid decorative dashboards, custom card grids, modal-heavy workflows, raw runtime-path dumps, contradictory status copy, hidden background activity, and visual treatments that compete with the active note. Do not imitate generic SaaS control panels inside Obsidian.

## Design Principles

- Keep the note and current task primary; operational controls stay compact and contextual.
- Make automation inspectable, reversible, and explicit about consent, limits, and failures.
- Prefer native Obsidian patterns and familiar platform affordances.
- Show actionable detail only when it helps the user decide or recover.
- Preserve local-first privacy and distinguish local processing from external research.

## Accessibility & Inclusion

Target WCAG AA contrast within active Obsidian themes. All controls must be keyboard reachable with visible focus, icons must include text or accessible labels, narrow windows must retain the current mode, and reduced-motion preferences must disable continuous decorative animation.
